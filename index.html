EVE 舰船中文 D-Scan

基于 dscan.info 设计理念的纯中文舰船识别工具 · 线上：dscan.dpdns.org

功能一览

  • D-Scan 解析 — 粘贴 EVE 扫描结果（本地 / 舰队 / D-Scan），自动识别中英文舰船名并按作战功能分组；精确到 typeID，玩家自定义船名不会误判
  • ECM 建议 — 扫描结果与浏览器中按舰船势力推荐 ECM 干扰（雷达 / 引力 / 磁力 / 光雷达 / 多谱式）
  • 舰船浏览器 — 浏览全部 531 艘舰船的中文数据，支持搜索 / 分类 / 科技等级 / 排序，每行附 ECM 建议；点船名查看详情
  • 舰船详情弹窗 — 空船属性（质量 / 槽位 / HP / 电容 / 无人机等）+ 船体加成（中文 traits）
  • 装备购买 Buy List — 粘贴资产 + 配装 → 扣除已有 → 生成需购买清单（资产 / 配装中英文混用均可）
  • ESI 查询 — 粘贴角色名列表，自动查询军团 / 联盟
  • 分享链接 — 每次解析生成独立短码，发给队友即看同结果 · 一键截图 结果存剪贴板 · 亮 / 暗主题

装备购买怎么用

  1. 游戏内 资产 / 机库窗口 全选 → 复制 → 粘贴到「装备购买」①（支持中英文，可多段 / 多角色拼一起）
  2. 复制一套 配装（游戏内复制 / Pyfa / EVE Workbench，中英文模块名都行）→ 粘贴到②
  3. 在 ③ 填要装的艘数 → 点「计算购买清单」
  4. 结果按需购买数排序（装备、弹药、无人机、船体都会算）；点「复制购买清单(Multi-Buy)」回游戏批量购买直接粘贴，或点「截图复制」存图

原理：通过 typeID 物品词典把中文资产与英文配装统一归并；需要量 = 单船配装 × 艘数，需购买 = 需要 − 已有。弹药 / 无人机按配装里的 xN 计算，船体单独抵扣。

项目结构

eve-dscan-cn/
├── index.html          主页面（页面 + CSS + JS 内嵌）
├── ships-data.js       舰船数据 531 艘（CCP SDE + ESI）
├── traits-data.js      船体加成中文数据 517 艘（everef ref-data）
├── items-data.js       物品中英文词典 5976 种（装备购买用，懒加载）
├── api.php / esi.php   PHP 缓存 API / ESI 代理
├── favicon.*           站点图标（make_icon.py 生成）
├── fetch_*.py          数据抓取脚本（属性 / 缺失船 / 加成）
├── build_items_vps.py  从 everef reference-data 生成物品词典
└── README.md

数据来源

  • 舰船数据：CCP EVE Online Static Data Export (latest JSONL) + ESI
  • 中文翻译：游戏内官方中文
  • 原始 Excel：EVE舰船分类大全_修正版.xlsx（423 艘，2026-07-20），后经 ESI 补充 108 艘（合计 531）
  • 物品中英文名：everef reference-data
