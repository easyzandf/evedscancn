EVE 舰船中文 D-Scan

基于 dscan.info 设计理念的纯中文舰船识别工具 · 线上：dscan.dpdns.org

功能一览

  • D-Scan 解析 — 粘贴 EVE 扫描结果（本地 / 舰队 / D-Scan），自动识别中英文舰船名并按作战功能分组；精确到 typeID，玩家自定义船名不会误判
  • ECM 建议 — 扫描结果与浏览器中按舰船势力推荐 ECM 干扰（雷达 / 引力 / 磁力 / 光雷达 / 多谱式）
  • 舰船浏览器 — 浏览全部 531 艘舰船的中文数据，支持搜索 / 分类 / 科技等级 / 排序，每行附 ECM 建议；点船名查看详情
  • 舰船详情弹窗 — 空船属性（质量 / 槽位 / HP / 电容 / 无人机等）+ 船体加成（中文 traits）
  • 装备购买 Buy List — 粘贴资产 + 配装 → 扣除已有 → 生成需购买清单（资产 / 配装中英文混用均可）
  • 30人本 / 战斗记录 — 粘贴本场角色名按时间存档；点记录复现名单，点头衔看该玩家名下所有号及两边参与数据；跨场分析出场次数、小号分布、时段与日期分布
  • ESI 查询 — 粘贴角色名列表，自动查询军团 / 联盟 / 头衔
  • 会战报告 — 把击杀流水自动切成一场场会战，每场给出双方对比（人数 / 损失 / 击毁 / 效率）、舰船编成、累计损失曲线、伤害排行和带筛选的击杀流水；点列表任意一场即可展开
  • 分享链接 — 每次解析生成独立短码，发给队友即看同结果 · 一键截图 结果存剪贴板 · 亮 / 暗主题

装备购买怎么用

  1. 游戏内 资产 / 机库窗口 全选 → 复制 → 粘贴到「装备购买」①（支持中英文，可多段 / 多角色拼一起）
  2. 复制一套 配装（游戏内复制 / Pyfa / EVE Workbench，中英文模块名都行）→ 粘贴到②
  3. 在 ③ 填要装的艘数 → 点「计算购买清单」
  4. 结果按需购买数排序（装备、弹药、无人机、船体都会算）；点「复制购买清单(Multi-Buy)」回游戏批量购买直接粘贴，或点「截图复制」存图

原理：通过 typeID 物品词典把中文资产与英文配装统一归并；需要量 = 单船配装 × 艘数，需购买 = 需要 − 已有。弹药 / 无人机按配装里的 xN 计算，船体单独抵扣。

30人本 / 战斗记录怎么用

「30人本」与「战斗」是两个独立的记录页：同一套界面和统计，但记录、同步码、服务器数据三者完全分开，互不影响。下面以 30人本 为例，战斗页操作完全相同。

本方 / 敌对

  • 本方军团固定为 PLA-F 与 P.L.A；其他军团（以及查不到军团的）一律归为敌对
  • 所有统计只算本方：出场排行、小号分布、玩家-角色对照、各项卡片都只含这两个军团；敌对只标注一个总角色数，不进入任何榜单
  • 本场名单分「本方 / 敌对」两大块，敌对块标红，一眼看出对面来了多少
  1. 复制本场参战名单（每行一个角色名即可，也可直接粘贴扫描原文自动提取）
  2. 点「解析并记录」→ 左侧按当前时间自动生成一条记录
  3. 点记录 → 看本场名单（按 头衔 → 军团 → 角色 展开，跨军团的号会分行并给出小计）
  4. 点角色名 → 该角色的个人出战面板；点头衔 → 该玩家名下所有号 + 30人本 / 战斗 两边的参与数据
  5. 切到「分析」→ 跨全部记录统计（概览卡片、人物与小号分布、出场排行、时段与日期分布）；顶部有筛选框可快速找人

面板与截图

角色面板和玩家面板右上角都有「截图复制」，一键把整块内容截到剪贴板；内容过长时会先自动展开再截，不会被裁掉。

记录存在哪

先写浏览器 localStorage（即时、离线可用），再同步到服务器 SQLite；左栏顶部显示同步状态（已同步 / 待同步 / 离线）。

站点是公开的，所以用同步码做隔离：服务器只存它的 sha256，没有同步码读不到任何记录。换设备时在「同步码」里填入同一个码即可取回记录；请务必自行留存——清浏览器缓存后丢失就只能靠导出的 JSON 找回（导出的文件里包含同步码）。

层面技术

项目结构

eve-dscan-cn/
├── index.html          主页面（页面 + CSS + JS 内嵌）
├── ships-data.js       舰船数据 531 艘（CCP SDE + ESI）
├── traits-data.js      船体加成中文数据 517 艘（everef ref-data）
├── items-data.js       物品中英文词典 5976 种（装备购买用，懒加载）
├── api.php / esi.php   PHP 分享缓存 / ESI 代理（单查 + 批量）
├── raid.php            30人本 & 战斗 记录 API（SQLite）
├── raid_data/          SQLite 数据目录（需 777 可写，勿提交）
├── favicon.*           站点图标（make_icon.py 生成）
├── fetch_*.py          数据抓取脚本（属性 / 缺失船 / 加成）
├── build_items_vps.py  从 everef reference-data 生成物品词典
└── README.md
